# TP 3 PHP : Suivi des notes des apprenants

**Auteur :** ABD ESSAMAD CHADLI  
**Date :** 18 Octobre 2026  

## Description
Ce dépôt contient l'intégralité de mon travail pour le TP3 de PHP. 
C'est une mini-application web qui permet de :
- Manipuler les variables, boucles et structures de contrôle
- Gérer des tableaux (simples et associatifs)
- Traiter des formulaires en GET et POST
- Lire et écrire dans des fichiers externes (CSV et JSON)
- Gérer un mini système d'authentification avec les sessions et cookies

## Architecture
- `config.php` : Constantes globales
- `exo1_bases.php` à `exo3_tableaux.php` : Exercices de base
- `info.html/php` & `saisie.html/traitement.php` : Formulaires
- `liste.php` & `export.php` : Fichiers CSV et JSON
- `login.php`, `profil.php`, `deconnexion.php` : Espace membre
- Dossier `includes/` : Morceaux de pages (header, menu, footer)
- Dossier `data/` : Fichiers de sauvegarde des notes
